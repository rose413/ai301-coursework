I opened my first open source contribution to Simpler Grants, the U.S. Department of Health and Human Services' project to modernize Grants.gov. I built a new feature that lets an organization see all of its in-progress and submitted grant applications in one list, newest first, and only people from that organization with permission to view applications can see it.

Before, there was no way to request that list at all. I built it by following a similar feature already in the project, and wrote 11 tests that check it shows the right applications, keeps each organization's data private, and turns away anyone without access.

My pull request is open and waiting for review from the project's maintainers.

What I took away from it:
🔧 Getting a large project running on my own computer is part of the work. I had to solve a memory problem before I could even start.
📋 Clear plans pay off. A vague first plan got flagged by my own checklist, and naming every file and test made the build much smoother.
🤖 AI tools helped me understand the code faster, but I read and checked every line before submitting.
